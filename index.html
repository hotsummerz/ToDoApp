    Catatan Teknis

    Git & GitHub

    Git adalah version control system yang merekam perubahan kode dalam bentuk commits. Branch memungkinkan pengembangan fitur secara terisolasi. Merge menggabungkan perubahan dari satu branch ke branch lain. Conflict terjadi ketika dua branch mengubah baris yang sama; diselesaikan dengan memilih perubahan mana yang dipertahankan. GitHub adalah platform hosting untuk repository Git. Push mengunggah commits lokal ke remote, pull mengunduh dan merge perubahan dari remote. Pull Request adalah cara untuk mengusulkan dan mereview perubahan sebelum di-merge.

    npm

    npm (Node Package Manager) adalah package manager untuk JavaScript. package.json berisi metadata project, daftar dependencies, dan npm scripts. package-lock.json mengunci versi exact dari setiap dependency. node_modules/ menyimpan package terinstall. Dependencies adalah package yang dibutuhkan saat runtime (di-bundle ke aplikasi), sedangkan devDependencies hanya dibutuhkan saat development dan build. Semantic versioning: ^1.2.3 boleh update minor dan patch, ~1.2.3 hanya patch.

    TypeScript

    TypeScript adalah typed superset dari JavaScript yang menambahkan sistem tipe statis. Tipe membantu menangkap error saat development sebelum kode dijalankan. TypeScript di-transpile menjadi JavaScript biasa yang browser dapat eksekusi. Strict mode memaksa pengecekan tipe yang lebih ketat, mencegah bug umum seperti null/undefined errors.

    Vite

    Vite adalah build tool yang menyediakan development server dengan Hot Module Replacement (HMR) sangat cepat menggunakan native ES modules. Development server start instant tanpa bundling. Production build menggunakan Rollup untuk bundling, tree-shaking (menghapus kode tidak terpakai), dan minification. Vite dapat transpile TypeScript ke JavaScript menggunakan esbuild, tetapi tidak melakukan type-checking; untuk itu perlu menjalankan tsc terpisah.

    Environment Variables

    Environment variables memisahkan konfigurasi dari kode, sehingga nilai bisa berbeda per environment tanpa mengubah source code. File .env menyimpan variables lokal dan tidak di-commit ke Git. .env.example adalah template yang di-commit. Di Vite, hanya variables dengan prefix VITE_ yang di-expose ke client code, dan nilainya di-embed ke JavaScript bundle. Karena itu, JANGAN PERNAH menyimpan password atau API key di VITE_* variables.

    Compiler, Transpiler, dan Bundler

    Compiler menerjemahkan source code ke bentuk lower-level (contoh: C ke machine code). Transpiler menerjemahkan source code ke bahasa lain pada level abstraksi sama (contoh: TypeScript ke JavaScript). TypeScript Compiler (tsc) adalah transpiler yang juga melakukan type-checking. Bundler menggabungkan banyak file module menjadi sedikit file yang dioptimasi untuk browser, dengan tree-shaking, code splitting, dan minification.
